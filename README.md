# Kashif Iqbal

Web developer in Lahore. I turn classroom ideas into small, useful websites — and I publish the work so beginner students can learn from real code.

**[Lumen Labs](https://kashifch100.github.io/lumen-labs/)** is my open classroom: six beginner projects in HTML, CSS, JavaScript, and PHP. No frameworks. [View the source](https://github.com/kashifch100/lumen-labs).

## About

I have 5+ years of experience building web applications, from simple sites to fuller PHP and JavaScript products. I care about clear interfaces, clean code, and teaching the next student how to get unstuck.

I work best when the brief is real: a watermark tool, a store variation form, a classroom lab. In my free time I keep learning — React, better CSS, and whatever helps students ship their first public repo.
